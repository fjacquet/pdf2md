# Headings Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Every PDF heading comes out as a Markdown heading at its level in the document's hierarchy, and nothing else is promoted to a heading.

**Architecture:** Page analysis keeps deciding *whether* an element is a heading, with three rule fixes (start character, numbered lines, bold runs). The *level* moves to one document-wide pass: after all pages are collected, heading styles (size rounded to 0.5 pt, bold) are ranked and the rank is the level. The benchmark gains a heading F1 so every PR shows its effect.

**Tech Stack:** Go, READoc at `./READoc`, `cmd/benchmark`.

**Spec:** `docs/superpowers/specs/2026-10-28-headings-design.md`

## Global Constraints

- Pure Go, no new modules; CLI flags frozen (`TestCLIFlags`).
- Every rule is stated from typography (size, weight, line count, numbering) with a one-line comment saying why; no value tuned to particular READoc documents.
- Not touched: bullet characters, quote characters, link markup, tables, code blocks, ONNX.
- One PR per task. The READoc average and each subset's word F1 must not drop; the level-aware heading F1 must not drop on either subset (no tolerance, it is deterministic). Refresh `benchmark_baseline.json` with `-update-baseline`; merge on green CI.
- Golden files are refreshed with `go test ./cmd/pdf2md -run TestGolden -update` only when the diff is the task's intended change; the commit says so.
- Each PR adds a `CHANGELOG.md` entry under Unreleased. Lint: `golangci-lint run --fix ./...`, then `make lint`.
- Commits end with the session's `Co-Authored-By` and `Claude-Session` trailers.

## Review Focus

- **A document with no heading.** Expected: ranking is a no-op, nothing becomes a heading. Test in Task 3.
- **More than six heading styles.** Expected: the seventh and smaller are `######`. Test in Task 3.
- **A large running header or figure label repeated on every page** (largest style in the document). Expected: it takes `#`, and the real title drops one level; accepted limit, documented in the test. Test in Task 3.
- **A numbered body-size line that ends a paragraph** ("… as shown in 2. The result"). Expected: stays a paragraph or list item, never a heading. Test in Task 2.
- **A single bold line between paragraphs that is not a heading** (a bold sentence ending with a period). Expected: paragraph; the existing "no trailing `.`, `,`, `;`" check stays. Test in Task 2.
